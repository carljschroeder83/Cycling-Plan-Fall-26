Weeks — W6 deload + re-test
Systm library matching
  • Tue (MAP): filter 4DP focus = MAP, 60–80min. Read the interval breakdown: W1 ≈12min near MAP, W2 ≈16, W3 ≈20, W4/W5 ≈25, W6 ≈12 (priming). Mix long reps with micro-intervals (e.g. Half Is Easy, Micro Intervals, MAP Progression). Avoid AC and NM sessions.
  • Thu (FTP): filter 4DP focus = FTP, 60–75min. W1–2 sweet-spot style blocks; W3–5 threshold blocks (2×20 or 4×10).
  • Fri: Active Recovery category, 30–45min. Sat: outdoor. Workout names are candidates only: check each description.
  • ERG vs slope: ERG for Tue MAP reps and threshold blocks (stops over-cooking early reps). Slope for warm-ups, recoveries, Z2, Friday spin, sweet spot if you hold ±5W. Do not use ERG for the re-test efforts.
  • Pick gear before each rep, cadence 85–95rpm. If failing the last rep, drop 3–5% rather than stop. Follow Systm targets; watts here are a sanity check.
Weight & fuelling (107kg → 95–99kg by mid-March)
  • Deficit: ~400–500 kcal on Mon/Wed/Fri/Sun. Maintenance on Tue/Thu/Sat. Target 0.5–0.6kg/week on the 7-day mean of morning weights.
  • Intervals: carbs 60–90min before (bagel/white bread + jam + banana); bottle with 40–60g carb during sessions over 60min. Low-residue the day before key sessions.
  • Saturday ride: 60g carb/h. Never ride long fasted in a deficit.
  • Protein 190–210g, fat floor 85g. Loss over 0.8kg/week for 2 weeks, or interval targets missed twice: add 200 kcal.
Rules
Protect order

1 Tue VO2 · 2 Thu threshold · 3 Sat outdoor ride · circuits and Friday spin are cut first.

Deload = ceiling

W6 prescriptions are caps. Nothing extra before the Thursday re-test.

Travel

Keep Tue VO2 on any bike, else a hard 20–30min run. Drop circuits first. Two key sessions = a good week.

Missed reps

Miss the last 1–2 reps by over 5%: finish easy, add calories next day. Do not stack sessions.

Running (secondary)

One easy Sunday run. If legs are fresh, a second easy 5km can replace the Friday spin. Run before strength on the same day.
